# FitRecord 编译工具

> 面向本机构建/打包/测试的一站式说明。所有命令均在 **PowerShell** 下执行。
> 最近一次验证：`:app:assembleDebug` → `BUILD SUCCESSFUL`，产物 `app-debug.apk`（约 10.7 MB）。

## 3. 构建环境脚本 env.ps1

`android/env.ps1` 一次性注入所有环境变量并按需创建联接。**每次开新终端先 dot-source 它**（注意前面的点和空格）：

```powershell
cd D:\fitrecord\android
. .\env.ps1
```

它做了：设置 `JAVA_HOME` / `ANDROID_HOME` / `GRADLE_USER_HOME`、把 JDK 与 platform-tools 加入 `PATH`、创建 `D:\fitrecord`、`D:\gh` 联接，最后打印 `java -version` 供核对。

双保险：`gradle.properties` 里已钉死 `org.gradle.java.home=D:/insbuild/jdk17/jdk-17.0.20.1+1`，即使忘记 source env.ps1 也能编译。

## 4. 常用命令

均在 `D:\fitrecord\android` 下、且已 `. .\env.ps1` 后执行。

```powershell
# 只做 Kotlin 编译检查（最快，验证改动能否编过）
.\gradlew.bat :app:compileDebugKotlin

# 出调试包 → app/build/outputs/apk/debug/app-debug.apk
.\gradlew.bat :app:assembleDebug

# 出发布包（无 keystore.properties 时回退 debug 签名，仅可自测）
.\gradlew.bat :app:assembleRelease

# 跑全部单元测试（Robolectric + Compose UI 测试，测试 JVM 堆 2g）
.\gradlew.bat :app:testDebugUnitTest

# 清理构建产物
.\gradlew.bat clean
```


## 6. 签名说明

- 发布签名读取 `android/keystore.properties`（模板见 `keystore.properties.example`）+ 密钥库 `fitrecord-release.keystore`。
- `keystore.properties` 缺失或密钥库不存在时，release **自动回退 debug 签名**并打印 WARN——这种包只能自测，**不能用于覆盖升级**。
- Release 关闭 R8（`isMinifyEnabled = false`）：规避 Room / kotlinx-serialization 反射规则遗漏导致的运行期崩溃（见 `技术选型.md`）。
- 口令一旦丢失将无法对已安装 APK 覆盖升级，请自行备份 keystore 与 `keystore.properties`。

## 7. Room Schema

- KSP 参数 `room.schemaLocation = app/schemas`，导出版本化 schema（如 `.../FitRecordDatabase/1.json`）。
- `SchemaGuardTest` 从测试 classpath 读取该 JSON（以 resources 方式，路径不带 `schemas/` 前缀）。
- **改动数据库实体后必须同步递增版本号并导出新 schema**，否则 SchemaGuard 测试会失败。

## 8. 故障排查


| 现象                                                              | 根因                                              | 处理                                                  |
| --------------------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------- |
| `JAVA_HOME is not set` / `Unsupported class file major version` | 忘了 source env.ps1，或 `org.gradle.java.home` 路径写错 | 重跑 `. .\env.ps1`；核对 `gradle.properties` 里的 JDK17 路径 |
| AGP 拒绝构建 / `ClassNotFoundException: GradleWorkerMain`           | 从中文路径直接构建                                       | 切到 `D:\fitrecord\android` 再跑（见第 2 节）                |
| 测试 OOM / 卡住                                                     | Robolectric + Compose 默认堆太小                     | 已在 `build.gradle.kts` 设 `maxHeapSize = "2g"`，勿改小    |
| release 打 WARN 回退 debug 签名                                      | 缺 `keystore.properties` 或密钥库                    | 参照 `keystore.properties.example` 补齐                 |
| `Unable to strip ... libandroidx.graphics.path.so` 提示           | Windows 缺 native 剥离工具                           | 仅为告警，不影响打包结果，可忽略                                    |


## 9. 关键文件清单（android/）

```
env.ps1                      构建环境变量脚本（每次先 source）
gradlew.bat / gradlew        Gradle Wrapper 入口（8.9）
gradle.properties            org.gradle.java.home 双保险、overridePathCheck、jvmargs
local.properties             sdk.dir 指向本机 Android SDK
settings.gradle.kts          模块与仓库声明
app/build.gradle.kts         编译/签名/测试/Room 配置
keystore.properties(.example) 发布签名配置（.example 为模板）
app/schemas/                 Room 版本化 schema（勿手改，由 KSP 导出）
```
